# synergycorp-login

Static OAuth redirect page, privacy policy and terms for the private desktop app **SynergyCorp AI**.

- `oauth.html`: shows the one-time login code to copy into the desktop app. No network requests, no cookies, no trackers. The code is single-use and expires in minutes. It is useless without the client secret and PKCE verifier, which stay on the owner's computer.
- `privasi.html` / `syarat.html`: privacy policy and terms.

This repository contains no secrets, keys or personal data. Contributions are not accepted.
